# spaetzle-glas

A Three.js scene to display customized contents to a special person.

## Tech-Stack

- **Runtime:** Node.js (>= 22)
- **Sprache:** TypeScript (Strict Mode)
- **Test-Runner:** Vitest
- **CI/CD:** GitHub Actions
## Setup & Ausführung

```bash
npm install
npm run dev     # Hot-Reload Dev Mode
npm run test    # Tests ausführen
npm run build   # Production Build
```
